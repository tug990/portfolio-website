# Insight Lab portfolio: instructions for Claude

## STRUCTURE.md is the map. Use it on every edit.

1. **Before editing anything, read `STRUCTURE.md`** and use it to find the
   file(s) that own what you're asked to change.
2. **Only change the files you were told to change, or the files
   STRUCTURE.md says own that thing.** Don't edit, reformat, rename or
   "clean up" any other file. If the change seems to need another file,
   say which one and why before touching it.
3. **Keep STRUCTURE.md current in the same change.** Whenever you add, move,
   rename or delete a file, or change what a file is responsible for (a new
   export, a new section, a new constant people will tune, something becoming
   unused), update its entry, and the "Where to change common things" table
   if it applies. Update the "Last updated" date.

Everything else about this repo (what the site is, how to run it, working
rules for branches and PRs) is in `STRUCTURE.md`.
